# Plugin onboarding tour

Generated from the 15-step dependency-ordered tour skeleton in
`.guild/indexes/knowledge-graph.json` after the full Guild learn pass.

## Start here

The plugin is organized around lifecycle commands, specialist skills, hooks,
and deterministic scripts. Read the first steps in order, then use the layer
map to jump to a concern.

## Layer map

The learned graph partitions the codebase into Agent, Configuration, Core, Data,
Documentation, Hook, Skill, and Utility layers. The graph is the source for
node-level navigation; this guide does not reorder its tour.

## Ordered steps

1. **Plugin surface** — Start with the plugin manifests and shared agent
   contracts; they define what is installed and how work is handed off.
2. **Agent roster** — Follow the agent definitions and their shared settings to
   understand specialist ownership.
3. **Configuration and hooks** — Trace configuration, git hooks, and workflow
   entrypoints before reading implementation details.
4. **Lifecycle commands** — Read command resources as the public phase surface.
5. **Context and recall** — Follow context assembly and knowledge retrieval; the
   learned graph records the dependency edges.
6. **State and artifacts** — Inspect state readers/writers and artifact
   contracts; these are the durable evidence boundaries.
7. **Capability routing** — Study host/capability resolution and tier routing.
8. **Intake** — Follow prompt classification and phase selection.
9. **Operations** — Read operational runbooks and their safety rails.
10. **Specialist dispatch** — Follow roster composition and specialist skills.
11. **Learning pipeline** — Inspect map, graph, knowledge, and tour scripts.
12. **Telemetry** — Review run tracing, checkpoints, and provenance.
13. **Evaluation** — Follow goal/task schemas and traceability checks.
14. **Host adapters** — Inspect adapter contracts and host-neutral fallbacks.
15. **Verification** — Finish with verification and cross-host evidence gates.

This artifact is derived and can be regenerated from the learned graph.
