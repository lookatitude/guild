Blockers to fix first (repo code, reviewed PR)

  1. B1 · Claude receipt. The capture launches claude -p --plugin-dir <package>. That gives no native host identity. Since 5640fb1c (“defer ambiguous native receipts”, after PR #163) hooks/update-check.ts does not mint guild-install-receipt.json for a -beta.N version without host identity. The Claude worker requires that receipt, so it always refuses with owner_evaluation_error. A marketplace install does not fix this alone: native identity resolves to source: "host-registry", the hook mints only when source === "default" and the version is not beta, and the verifier expects a beta receipt with channel_confidence: "version-derived". The hook and the verifier now disagree on the receipt contract. Fix: a reviewed design change that makes them agree for beta (for example, the verifier binds Claude activation to host-registry identity instead of a minted receipt).
